# Target Adaptation as Editorial Rewriting

Target adaptation is not keyword substitution. Re-author the submission around the actual evidence, operations, controls, and limitations the selected surface receives.

## 1. Define the irreducible shot

Before selecting an operation, write:

```text
opening image
viewpoint profile and camera relation
dominant visible change
cause
performance detail
contact and prop continuity
landing image
dialogue and sound
must be exact
may vary
```

This is the creative truth that must survive target rewriting even when its carriers change.

The picture that shows it is not part of that truth. Fixed are the opening state, the landing, and the chain between them; the composition, scale, angle, and camera move that present them are chosen from what the surface draws reliably, and they change freely when the surface fails. A composition that comes back wrong twice with the same symptom is evidence about the surface, not a sentence to rewrite a third time: choose another picture of the same beat. A closer scale, a cut where a move was planned, the side of the room a reference already shows, an insert on the hands instead of a wide on the bodies. Holding to a shot the surface cannot draw spends runs on a preference the story never required.

## 2. Select the operation by the hardest evidence

Ask what is least replaceable:

- exact opening geometry;
- exact endpoint;
- recurring identity;
- complex motion timing;
- hand or body contact;
- camera path;
- exact dialogue;
- state transition;
- multi-character blocking.

Possible routes include:

- text generation for unconstrained composition;
- start image for exact opening geometry;
- first and last frames for exact endpoints;
- subject references for appearance;
- source edit or restyle for timing and camera;
- extension for continuation from accepted output;
- performance transfer for body, face, gesture, or speech;
- conventional edit and post when one pass is not appropriate.

Choose the operation that carries the hardest evidence, then route remaining requirements to compatible media, text, another pass, neighboring shots, or post-production.

## 3. Rewrite according to submitted evidence

The same scene needs different exact text when evidence changes.

### Text-only generation

The prompt establishes camera, scene, character placement, current state, action, physical response, and landing.

### Complete start image

The image carries opening composition, visible identity, state, and camera. Text concentrates on action, performance, physical response, and landing.

### Start and end frames

The images carry both endpoints. Text directs the physically plausible path and preserves state, contact, and prop ownership.

### Character references without a start image

References carry visible appearance. Text must still establish external camera, scale, blocking, environment, contact, action, and landing.

### Source video edit or restyle

Source carries timing, camera, motion, and existing contact. Text states what remains and what changes.

### Extension

Accepted source carries the real opening. Text begins from actual camera, pose, state, prop, and audio tail.

These are different submissions because the target receives different evidence, not because the suite changes an abstract mode value.

## 4. Translate viewpoint into concrete target direction

The target may not understand a viewpoint profile label. Translate it into:

- camera ownership;
- camera position or owner body state;
- focalization;
- point of audition;
- shot scale, angle, lens, and movement;
- visible limbs, subjects, and identity details;
- screen direction, axis, and eyeline;
- start and landing anchors;
- viewpoint transition bridge when applicable.

Keep the internal profile in production records for validation and review.

## 5. Prompt rewriting and hidden transformation

When a service rewrites prompts:

- preserve exact submitted text;
- preserve returned rewritten text when available;
- compare outcomes across controlled submissions;
- move fragile identity, state, and geometry into submitted media;
- avoid attributing behavior to wording alone when the rewritten prompt is unknown;
- record the effect as dated target evidence.

Prompt rewriting changes the evidence available for diagnosis. It does not justify deleting detailed direction from the director package.

## 6. Negative and exclusion fields

Use a separate field only when the exact surface exposes and documents it. Primary text and submitted media still construct desired camera, state, action, contact, and landing.

Before submission:

- compare primary and negative fields together;
- remove stale exclusions left by earlier revisions;
- keep concise unwanted artifact categories in the negative field;
- keep constructive desired behavior in the primary field and media;
- record the exact field or request key.

A negative field is an additional channel, not the whole design.

## 7. Viewpoint-specific fallback

When a target cannot generate a planned multi-viewpoint sequence in one pass:

1. split shots by viewpoint;
2. generate or author boundary media for each shot;
3. use source edit for difficult camera motion;
4. bridge with action, eyeline, object, sound, occlusion, or light;
5. conform and finish the cut in post;
6. preserve one shared state and continuity ledger across all operations.

Do not force all coverage into one prompt when the target has no mechanism for controlled internal cuts.

## 8. State-specific fallback

When the target loses a state feature:

- confirm selected references visibly support it;
- confirm the shot can see it;
- move it into a start or end image when visually critical;
- choose a better angle-matched reference;
- simplify competing action;
- use edit or identity correction;
- route a small surface repair to post;
- accept variation only when canon and user approval allow it.

Record whether the failure belonged to candidate media, identity or state contract, reference selection, shot geometry, target behavior, or finishing.

## 9. Adaptation trace

For every final submission, record where each requirement went:

```text
retained in primary text
carried by submitted media
moved to auxiliary field
moved to another generation or edit
moved to post-production
carried by neighboring shot
accepted as variation
unresolved
```

This trace prevents rich direction from disappearing during concise target rewriting.

## 10. Observable distinction test

A target distinction belongs in the workflow only when it changes at least one concrete artifact:

- created or submitted media;
- target control or request key;
- exact text;
- settings;
- clip or shot split;
- post-production route;
- review evidence;
- fallback.

If two named strategies produce the same files, controls, text, and review, merge the labels while preserving the useful directing knowledge.

## 11. Target adaptation completion test

- the irreducible shot is clear;
- the chosen operation carries the hardest evidence;
- input combinations are documented or directly observed;
- all files map to real controls;
- exact text reflects what media does and does not supply;
- viewpoint grammar is translated into concrete camera direction;
- identity and state have carriers;
- primary and negative fields agree;
- unsupported requirements have alternate routes;
- the adaptation trace is complete;
- run status remains truthful.
